# 🤍 5th Month Anniversary Special Tribute

A beautifully crafted, interactive digital anniversary experience designed to celebrate 5 months of togetherness. This project is a blend of clean, aesthetic web design and heartfelt interactivity, built to create a lasting memory.

## 🚀 Features
This web application is packed with love and technology:
* **Romantic Atmosphere:** A custom-built music player to set the perfect mood.
* **Interactive Love Quiz:** A fun way to test how well we know our journey together!
* **Love Meter:** A playful feature to calculate our soulmate connection.
* **Secret Envelopes:** Personalized "Open When" notes for every mood.
* **Aesthetic Design:** A modern, dark-themed UI with glassmorphism and floating heart animations.
* **Responsive:** Fully optimized for both mobile and desktop screens.

## 🛠 Tech Stack
* **HTML5:** For structured layout and content.
* **CSS3:** For modern animations, glassmorphism, and responsive styling.
* **JavaScript:** For interactive features like the quiz, music toggle, and modal popups.

## 💡 Why This Project?
This project isn't just a website; it's a digital memory vault. It demonstrates the power of combining simple coding logic with meaningful UI/UX to create personalized digital gifts—a trend that is transforming how we celebrate special milestones in the digital age.
